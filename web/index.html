Musical strategy

Captured pitches are interpreted as scale degrees. The answer begins near a fifth above, reverses the source direction in diatonic steps, stays within a safe register, and cadences on the tonic, third, or fifth.

Deliberately constrained

This first musical strategy keeps the original rhythm and uses a manually selected key. Automatic key detection, chord progressions, Adventure, and rhythmic mutation remain later experiments.

Browser simulation, not a full CPU emulator or a hardware compatibility test. Memory lasts until Clear, a new capture, or closing the page. No installer or hardware access.
